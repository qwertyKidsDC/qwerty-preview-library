project · 02

Mini build: detect motion

Connect your PIR according to the labels on your exact module. Use a GPIO Zero MotionSensor.

from gpiozero import MotionSensor

pir = MotionSensor(4)

print("Waiting for movement...")
pir.wait_for_motion()
print("Something moved")
Wave a warm hand across the sensor. The message should appear once motion is detected.
project · 03

Mini build: make motion visible

Add the LED circuit from the GPIO deck. This gives you a visible test before the camera enters the system.

from gpiozero import MotionSensor, LED

pir = MotionSensor(4)
led = LED(17)

pir.when_motion = led.on
pir.when_no_motion = led.off

input("Press Enter to stop")
If this works, the PIR and GPIO logic are proven.
project · 04

Attach the camera safely

  1. Shut the Pi down.
  2. Remove power.
  3. Identify the correct camera connector for your Pi model.
  4. Open the connector latch carefully.
  5. Insert the ribbon cable in the correct orientation for that model.
  6. Close the latch; then restore power.
Do not copy ribbon orientation from a random photo. Pi models and cable types differ.

project · 07

Take a photo with Python

Picamera2 is the current Python camera library on Raspberry Pi OS.

from picamera2 import Picamera2
from time import sleep

camera = Picamera2()
camera.start()
sleep(2)
camera.capture_file("latest.jpg")
camera.stop()

print("Photo saved")
Run it twice. The second capture should replace latest.jpg.
project · 08

Combine motion + camera

from gpiozero import MotionSensor
from picamera2 import Picamera2
from time import sleep

pir = MotionSensor(4)
camera = Picamera2()
camera.start()
sleep(2)

print("Lucky Cam is watching...")

while True:
    pir.wait_for_motion()
    camera.capture_file("latest.jpg")
    print("New photo!")
    pir.wait_for_no_motion()
The final wait_for_no_motion() prevents one continuous movement from immediately firing photo after photo.
project · 09

Make the latest image viewable

First prove the idea on your local network. Put a tiny index.html beside latest.jpg, then serve the folder:

cd ~/pi-projects/cat-cam
python3 -m http.server 8000

Another device on the same network can open the Pi's address and view the folder/page.

This is a local test, not safe public internet hosting. Public publishing needs a deliberate upload/hosting method.

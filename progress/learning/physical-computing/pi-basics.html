Raspberry Pi basics.

A beginner's guide to the Pi as a real Linux computer: what the board is, how files and Terminal work, and how Python fits in.

Studio deck
01 · orientation

A Raspberry Pi is a real computer

It is small enough to hold in one hand, but it runs an operating system, stores files, connects to networks and runs Python just like a much larger computer.

Computer jobs

Files · programs · web · networking · Linux · Python

Maker jobs

Sensors · lights · buttons · motors · cameras · GPIO

The interesting bit is that one machine can do both.
02 · hardware tour

Meet the board

  • Find the 40-pin GPIO header.
  • Find power and display connectors.
  • Find USB and Ethernet.
  • Find the microSD card.
  • Find the camera connector on your model.
Do not plug or unplug GPIO or camera hardware while the Pi is powered.
03 · start + stop

Boot it. Shut it down properly.

The microSD card is the Pi's storage. Pulling power while Linux is writing to it can corrupt files.

Start

Connect display, keyboard/mouse if needed, then power.

Work

Save files in a project folder you can find again.

Stop

Use the Shut Down menu or sudo shutdown -h now. Wait before unplugging power.

04 · operating system

Raspberry Pi OS + Linux

Raspberry Pi OS is the operating system. It is based on Linux. You can use the desktop and the Terminal: they are two ways of working with the same computer.

DesktopTerminal
Click folders, apps and menus.Type commands to inspect and control the system.
Great for browsing files and using graphical apps.Great for precise, repeatable tasks and remote work.
05 · files

Know where your stuff is

A project is easier when its files live together.

home/
└── your-name/
    └── pi-projects/
        ├── hello.py
        └── cat-cam/

Create a folder called pi-projects. Later Cat Cam can have its own folder inside it.

06 · terminal

Terminal: tiny vocabulary, big usefulness

pwd
ls
cd
mkdir
clear

pwd = where am I?

ls = what is here?

cd = move to another folder.

mkdir = make a folder.

clear = tidy the screen.

You do not need to memorise Linux. You need to know how to find out what a command does.
07 · mini mission

Make a project folder using Terminal

cd ~
mkdir -p pi-projects/first-pi
cd pi-projects/first-pi
pwd
ls
Checkpoint: pwd should end in pi-projects/first-pi.
08 · python

Run Python in Thonny

Open Thonny and create a file called hello.py.

print("Hello from the Pi")

Run it. Then save it inside your first-pi folder.

The editor helps you write code. Python runs the code. The file is yours.
09 · same file, new route

Run that file from Terminal

cd ~/pi-projects/first-pi
python3 hello.py

Same file. Same Python. Different way of starting it.

If the message appears, you have connected Linux folders, Terminal and Python.
10 · checkpoint

Electronics + GPIO.

Enough electronics to build confidently and safely: input, output, the 40-pin header, and two tiny builds that make GPIO make sense.

Studio deck
01 · lab habits

Five rules before the first wire

  1. Power off before changing wiring.
  2. Check the pin twice before powering on.
  3. GPIO logic is 3.3 V. Do not feed 5 V into a GPIO pin.
  4. Use a resistor with a normal LED.
  5. Motors and other higher-current loads need driver circuitry; do not power them directly from GPIO.
Unsure? Stop. Trace the wire from one end to the other before switching on.
02 · useful electronics

Voltage, current, resistance

Voltage

The electrical push between two points.

Current

The amount of charge flowing.

Resistance

Limits current. Very useful when an LED would otherwise take too much.

You do not need a physics lecture before making things. You do need enough understanding to wire them safely.

03 · big idea

Input or output?

INPUT

The world tells the Pi something.

Button · PIR · light sensor · distance sensor

OUTPUT

The Pi tells something to happen.

LED · buzzer · display · servo (through suitable control)

Cat Cam begins with an input: “something moved”. Then the Pi causes an output: “take a photo”.
04 · GPIO

General Purpose Input / Output

Some pins provide power. Some are ground. Many are programmable GPIO pins.

GPIO outputs can be LOW (0 V) or HIGH (3.3 V). Inputs can read LOW or HIGH.

The 5 V pins are power pins. They are not “stronger GPIO”.
05 · numbering

Physical pin ≠ GPIO number

A header pin has a physical position and may also have a GPIO/BCM number.

Example: physical pin 11 is GPIO17.
pinout

On Raspberry Pi OS, the pinout command gives you a reference for the board. Use it rather than guessing.

06 · mini build A

Pi → world: blink an LED

Wire while powered off

  1. GPIO17 → resistor (220–330 Ω).
  2. Resistor → LED long leg (anode).
  3. LED short leg (cathode) → GND.
from gpiozero import LED
from time import sleep

led = LED(17)

while True:
    led.on()
    sleep(1)
    led.off()
    sleep(1)
You have made software control a physical output.
07 · mini build B

World → Pi: read a button

Wire while powered off

Use a pushbutton between GPIO27 and GND. GPIO Zero can use the Pi's internal pull-up resistor.

from gpiozero import Button

button = Button(27)

button.wait_for_press()
print("Button pressed")
You have made a physical input change software behaviour.
08 · library

Why use GPIO Zero?

GPIO Zero gives friendly Python names to common hardware: LED, Button, MotionSensor and more.

from gpiozero import MotionSensor

pir = MotionSensor(4)
pir.wait_for_motion()
print("Something moved")
The class names describe the thing you are using, not just the electrical pin underneath it.
09 · debugging

When nothing happens

  1. Turn power off.
  2. Check the physical pin and GPIO number.
  3. Check ground.
  4. Check component direction/polarity.
  5. Check code names and indentation.
  6. Reduce the system to one tiny test.
Debug one layer at a time: power → wiring → pin → tiny code → full project.
10 · checkpoint

You are ready for sensors

  • I know the difference between an input and output.
  • I know GPIO logic uses 3.3 V.
  • I can identify power, ground and GPIO pins.
  • I know physical pin numbers and GPIO numbers are not the same thing.
  • I have controlled an LED and read a button.

Minecraft Python Project Lab — tutor notes

What this deck is: a curated student project chooser linking to ten independent original tutorials. The book is already held by Qwerty. It is not a tested rewrite or a promise that historical code runs unchanged on Python 3.

The MagPi Issue 41, Minecraft Mashups (January 2016): magazine feature on printed pp. 16–25, which are PDF pp. 18–27 in the uploaded file. The Natural Disasters article, Sense HAT controller, Sonic Pi VJ and Node-RED overlap material in Essentials. Printed p. 19 has short project descriptions for Control an LED with Minecraft and Control Minecraft with a Button; these are ideas, not full step-by-step lesson builds.

Source corrections: The magazine Python API overview on printed p. 17 (PDF p. 19) incorrectly describes the axes (Y is vertical, Z is horizontal in Minecraft Pi), has Python 2 print examples, and includes a getBlack typo. Do not use it directly as a student reference; refer to Essentials pp. 81–98 instead. The magazine Walking with Steve example explicitly says Python 2.7.

Status: PDFs inspected and page-mapped; compatibility and safety notes are based on source review. No code from these two PDFs was executed on the Qwerty Raspberry Pis.

01 · Start making

Make something with code.

Open Processing. It is already installed. Your first job: put a shape on the screen.

  1. In Processing, choose File → New.
  2. Make sure the mode selector says Java (usually near the upper-right).
  3. In the blank editor, type the entire sketch below.
  4. Click the Run ▶ button.
Type this entire sketch
void setup() {
  size(600, 600);
  background(14, 18, 32);
  noStroke();
  fill(146, 214, 68);
  circle(300, 300, 160);
}
Test 01A 600 × 600 window appears. It has a dark background and one large green circle in the middle.
If you see an error insteadLook for the highlighted line in Processing. Check the brackets { }, the semicolons ; and each spelling. Do not move on until the circle appears.
02 · Experiment

Three numbers. Endless possibilities.

circle(300, 300, 160) means centre X, centre Y, diameter.

  1. Change the first 300 to 120. Run. What moved?
  2. Change the second 300 to 450. Run again.
  3. Try changing 160 to 45. Run again.
  4. Now invent a colour by changing the three numbers in fill(146, 214, 68).
CoordinatesThe top-left of the canvas is (0, 0). X increases to the right. Y increases down the screen. In fill(red, green, blue), colour values usually go from 0 to 255.
Mini challengePut the circle near each of the four corners. How small must its diameter be to fit?
03 · Studio habit

Save the experiment.

In Processing, a program is called a sketch. Give yours a proper home before you start breaking things (in a useful way).

  1. Choose File → Save As….
  2. Enter the sketch name baterdene_shape_lab.
  3. Choose a folder you can find again. Click Save.
  4. Choose Sketch → Show Sketch Folder. Find the .pde file inside.
  5. Return to Processing, press Run and confirm that it still works.
Test 03You can locate your saved sketch and reopen it. Processing keeps the code in a file ending with .pde.
Studio habitWhen you make a big change you like, use Save As to make another version. Experiments are more fun when you can go backwards.

06 · Repetition

One circle becomes nine.

Go back to baterdene_shape_lab. Keep the rest of your setup() exactly as it is.

  1. Find the one circle(...); line inside setup().
  2. Delete only that line.
  3. Type this three-line loop in its place.
  4. Press Run. Count nine circles before changing anything else.
  5. Now change the 60 in x += 60 to 90. Run again. How many circles are there?
  6. Change 90 back to 60 and Run once more before moving on.
Replacement for the single circle line
for (int x = 60; x <= 540; x += 60) {
  circle(x, 300, 30);
}
Test 06With x += 60, you see 9 circles. With x += 90, you see 6 circles. The loop starts at 60, adds the step size, and stops after the value passes 540.
Read the codeint x creates a whole-number variable called x. The loop changes it for each new circle. Keep the surrounding setup() { ... } brackets.
07 · Nested loops

Turn the row into a grid.

One loop moves across the canvas. Another loop moves down it.

  1. Find the entire three-line for loop from the last step.
  2. Replace that whole loop with the new loop below, still inside setup().
  3. Run. Count the rows and columns.
Replacement loop
for (int y = 60; y <= 540; y += 60) {
  for (int x = 60; x <= 540; x += 60) {
    circle(x, y, 30);
  }
}
Test 07Nine columns × nine rows = 81 circles. The outer loop changes Y. The inner loop changes X.
ExperimentChange the step size of one loop. Can you make a rectangle of dots instead of a square? Then restore both loop increments to 60 for the next page.
08 · Rules for colour

Let the position choose the colour.

  1. Delete the old fill(146, 214, 68); line near the top of setup().
  2. Inside the inner loop, find circle(x, y, 30);.
  3. Insert this new fill line directly above that circle line.
  4. Run. Then swap x / 3 and y / 3. Run again.
Your inner loop should look like this
for (int x = 60; x <= 540; x += 60) {
  fill(x / 3, 90, y / 3);
  circle(x, y, 30);
}
Test 08The 81 dots stay in the grid, but their colours change with their positions. Dividing X and Y by 3 keeps the colour values in range for this sketch (0–255). You are using coordinates as design ingredients.
09 · Rules for size

Make the circles grow.

  1. Keep the grid and its new colour rule.
  2. Find circle(x, y, 30);.
  3. Replace that one line with the line below.
  4. Run. Now try y / 12 in place of x / 12.
Replace one line
circle(x, y, x / 12);
Test 09The circles grow larger from left to right. Your drawing now has a size rule and a colour rule.

10 · Animation

Now make something move.

We'll make a second sketch so you can keep your grid artwork.

  1. Choose File → New.
  2. Type the entire sketch below into the blank editor.
  3. Press Run. Watch the pink circle.
  4. Save the sketch as baterdene_motion_lab.
A new complete sketch
void setup() {
  size(600, 600);
  noStroke();
}

void draw() {
  background(14, 18, 32);
  float x = width / 2 + sin(frameCount * 0.035f) * 190;
  fill(246, 109, 193);
  circle(x, height / 2, 80);
}
Test 10The circle travels smoothly left and right. setup() runs once and draw() repeats. frameCount counts the frames, while sin() produces a back-and-forth wave.
Small experimentOn the line starting float x =, change 0.035f to 0.070f. Run: does it move faster or slower? Keep the letter f at the end — it marks a decimal number in this Java-style sketch. Restore the original number if you prefer.
11 · Interaction

You are the controller.

Instead of letting a mathematical wave decide where the circle goes, make it follow your mouse.

  1. In baterdene_motion_lab, locate the line that starts float x =. Delete only that entire line.
  2. Find circle(x, height / 2, 80);.
  3. Replace it with circle(mouseX, mouseY, 80);.
  4. Run. Move your mouse around inside the sketch window.
Your full draw() function now
void draw() {
  background(14, 18, 32);
  fill(246, 109, 193);
  circle(mouseX, mouseY, 80);
}
Test 11The pink circle follows your pointer. mouseX and mouseY are values Processing updates for you.
12 · Interactive artwork

Paint by dragging.

Make the circle leave a trail only while you hold the mouse button down.

  1. Keep baterdene_motion_lab open. Find background(14, 18, 32); inside draw().
  2. Cut that one line and move it into setup(), directly after size(600, 600);. The background will now be drawn only once.
  3. Inside draw(), delete the old fill(...); and circle(...); lines, but keep both curly brackets of the function.
  4. Type the four-line if (mousePressed) block below inside draw(). Keep its indentation and closing bracket.
  5. Run. Hold the mouse button down and drag across the sketch window. Release the button and move again.
Your draw() should now be
void draw() {
  if (mousePressed) {
    fill(246, 109, 193, 80);
    circle(mouseX, mouseY, 35);
  }
}
Test 12A trail of pink dots appears only while the mouse button is held down. Releasing the button stops the brush. Older dots remain on the canvas.
If the whole canvas is still clearingThere must be no background(...); line inside draw(). Your setup() should contain, in order: size(600, 600);, background(14, 18, 32);, then noStroke();. The word mousePressed here is a built-in true/false value.
13 · Randomness

Make an unpredictable brush.

  1. Keep the same sketch. Do not change setup() or the if (mousePressed) { ... } line.
  2. Inside that if block, replace only the existing fill(...); line with the one below.
  3. Replace only the existing circle(...); line with the second line below.
  4. Run. Hold and drag to paint some colourful marks.
Replace these two lines inside the if block
fill(random(256), random(256), random(256), 100);
circle(mouseX, mouseY, random(10, 50));
Test 13Your brush paints with changing colours and sizes while you drag. random(256) chooses a new value from 0 up to (but not including) 256.
Make a signature paletteTry replacing the first random(256) with 246 and the second with random(40, 130). Run. How did your colour palette change? Keep the lines inside the if brackets.
14 · Make it usable

Press C to clear.

Painting uses the mouse. Clearing should use a different control, so you never accidentally delete your artwork.

  1. Keep setup() and draw() exactly as they are.
  2. Go to the very bottom of the sketch, after the final closing bracket } of draw().
  3. Add this new, separate keyPressed() function. Match the brackets exactly.
  4. Run. Paint a trail; release the mouse; then press C with the sketch window active.
Add below draw() — not inside it
void keyPressed() {
  if (key == 'c' || key == 'C') {
    background(14, 18, 32);
  }
}
Test 14Your entire canvas becomes dark again when you press C. Click-and-drag still paints new dots. || means “or”: lowercase or uppercase C will work.
If nothing happens when you press CClick the sketch window (without dragging) to give it keyboard focus, release the mouse, then press C. If the code is in draw() by mistake, move it below the function instead.
15 · Export

Press S to save an artwork.

Keep your C-to-clear shortcut. Add another shortcut to export your drawing as a PNG image.

  1. Find the entire keyPressed() function from page 14, including its outer brackets.
  2. Replace that whole function with the updated version below. Keep setup() and draw() untouched. You should have exactly one keyPressed() function.
  3. Run. Hold and drag to paint. Release the mouse, then press S with the sketch window active.
  4. In Processing, choose Sketch → Show Sketch Folder. Look for a PNG beginning with baterdene-.
  5. Return to the sketch window. Press C and check that clearing still works.
Replacement keyPressed() function
void keyPressed() {
  if (key == 'c' || key == 'C') {
    background(14, 18, 32);
  }
  if (key == 's' || key == 'S') {
    saveFrame("baterdene-####.png");
  }
}
Test 15Pressing S saves your picture as a PNG in the sketch folder, and pressing C still clears. The four # characters are replaced by the current frame number.
Make a mini exhibitionPaint and save three images with distinct palettes, brush sizes or movement. Explain what you changed. Press C between each image.

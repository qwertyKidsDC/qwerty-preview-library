PATTERN 06CONTENT-SECTION

THE DELIBERATELY BORING ONE

Not every section needs to perform.

Some pages will need room for explanation, schedules, policies, practical details, longer-form writing or a sequence of ideas. This pattern keeps that content readable without forcing it into coloured cards.

It can contain headings, paragraphs, lists, inline images, tables and links while still belonging to the same visual system.

  • Readable line length
  • Flexible vertical rhythm
  • No fixed section height

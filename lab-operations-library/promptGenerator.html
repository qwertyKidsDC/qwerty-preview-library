Toggles

Follow-up Offers

  • ++offers — Include extra suggestions / follow-ups
  • --offers — No extra suggestions unless asked

Answer Length

  • ++brief — Short answers (1–3 sentences)
  • ++deep — Detailed, step-by-step
  • --brief / --deep — Reset length to normal

Tone

  • ++casual — Friendly, relaxed style
  • ++formal — Professional, academic style
  • ++kid — Simplified, child-friendly explanations
  • --casual / --formal / --kid — Reset tone

Output Format

  • ++json — Reply only in JSON
  • ++table — Use tables where possible
  • ++checklist — Use checkboxes for steps
  • --json / --table / --checklist — Back to normal prose

Mode Lock

  • ++teacher — Stay in teacher/guide role
  • ++critic — Blunt, critical mode
  • ++examiner — Quiz + check answers
  • --teacher / --critic / --examiner — Reset to default

Strategic Thinking

  • ++strategic — Long-term fit, positioning and consequences
  • ++risk — Focus on failure modes and weak assumptions
  • ++tradeoffs — Compare costs, benefits and opportunity cost
  • --strategic / --risk / --tradeoffs — Reset strategy lenses

Commands

Core Commands

  • /explain [topic] — Clear explanation; choose depth
  • /expand [text] — Add detail and examples
  • /shrink [text] — Summarize / compress
  • /debug [code] — Find & fix issues
  • /optimize [code/process] — Faster / shorter
  • /rewrite [style] — Change tone/voice
  • /compare [A] vs [B] — Pros/cons and trade-offs
  • /critique [idea] — Find weak spots and risks
  • /assumptions [idea] — Test hidden assumptions
  • /stress-test [idea] — Find flaws and failure modes
  • /rank [options] — Rank options with reasons
  • /recommend [options] — Choose and explain why
  • /stepbystep [process] — Full walkthrough
  • /check [text] — Proofread & validate
  • /simulate [situation] — Roleplay scenario
  • /generate [list/plan/code] — Create new content

Symbols & Shortcuts

  • `inline` — highlight code/terms
  • ``` (triple backticks) — code blocks
  • # — heading; -/* — bullets; > — quote
  • { } — structured output (JSON/configs)
  • --- — section break
  • Custom: >>S summarize, >>E explain, >>Q quiz

Thinking Prompts

  • Don’t just answer quickly. Stress-test it.
  • Challenge my assumptions.
  • Tell me what’s weak, unclear, or risky.
  • Compare the options before choosing.
  • Give me the best answer, not the nicest one.
  • Point out anything inconsistent.
  • Show your reasoning briefly, then your conclusion.
  • What would make this fail?
  • What’s missing or unclear?
  • What would a high-end version look like?
  • Cut anything weak or unnecessary.
  • Make this harder to ignore.

Iteration Tricks

  • Draft Cycle — Draft → critique → improve → repeat
  • Self-Check — “Check your answer & fix mistakes”
  • Multi-Perspective — “Answer as teacher, then student”

Constraints & Rules

  • Length — “≤50 words” / “max 3 bullets”
  • Format — JSON / table / checklist
  • Audience — “for a 10-year-old / expert”
  • Focus — “Only output code / facts / diagrams”

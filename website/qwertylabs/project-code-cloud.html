CODE CLOUD

Where does your code go after you click Download?

Tiarna and Chloe built a cloud full of lights, buttons and sounds to make the journey visible.

MINE'S BROKEN

Tiarna and Chloe were helping younger children code BBC micro:bits when they noticed a pattern.

The children would finish writing their code, try the simulator and announce that their micro:bits were broken. Sometimes before they'd even plugged them in.

But where was their code? On the website? On their computer? On the micro:bit?

So Tiarna and Chloe decided to build something that would make the whole process visible.

WHERE CODE GOES

Project Code Cloud is a physical model of how code moves between a coding website, the cloud, a computer and a device.

Press a button to simulate downloading, uploading, pairing or syncing. Lights and sounds show what's happening at each stage.

Sometimes pairing fails. Sometimes the cloud goes offline. That's deliberate. Real technology doesn't always cooperate either.

WHAT THEY BUILT

Tiarna and Chloe programmed a Raspberry Pi, wired LED strips, built electronic circuits and designed the physical structure.

One of the trickiest problems was making sure the system could handle someone pressing another button before the previous action had finished. An entirely predictable problem when your audience includes enthusiastic children.

COOLEST PROJECTS

In 2026, more than 15,000 young people from 40 countries shared over 4,500 creations at the Raspberry Pi Foundation's Coolest Projects showcase.

Project Code Cloud was the only Australian project among the international VIP judges' favourites, and one of four hardware projects they selected. Sebin Sunny chose it as his hardware favourite.

We shared the news with Prime Minister Anthony Albanese. His office wrote back to congratulate Tiarna and Chloe on their creativity, innovation and technical skills.

Coolest Projects celebrates making and sharing, rather than competing. That's what made the recognition particularly lovely.
